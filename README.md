# Upa

**What rent really costs in the Philippines, and stays you can book. Built to show off PostgreSQL.**

Upa ("rent" in Filipino) has two halves:

- **Merkado:** daily market figures from public rental and sale listings on Dot Property:
  medians, percentiles, ₱/m², trends, gross yields and an "Is this rent fair?" checker.
- **Stays:** demo hosts list condos, rooms and houses; guests search, book and review.

The rules that matter live in the database. See [the Under the hood page](src/app/under-the-hood.tsx)
or [docs/PLAN.md](docs/PLAN.md) for the full list. Some highlights:

| Postgres feature | What it does here |
|---|---|
| `EXCLUDE USING gist (stay_id WITH =, during WITH &&)` | Double bookings are impossible, even under concurrency |
| Row-level security | Guests see their trips, hosts see bookings on their stays |
| PostGIS `geography`, `ST_DWithin`, `<->` | Radius search, nearest first, map-area search |
| `tsvector` + `pg_trgm` + `unaccent` | Typo- and accent-tolerant search |
| `percentile_cont`, `GROUPING SETS`, window functions, materialized view | Market statistics |
| `percent_rank(x) WITHIN GROUP` | "Is this rent fair?" |
| `MERGE … RETURNING merge_action()`, partitioning | Scraper ingest and price history |
| `pg_cron`, Realtime | Nightly jobs, live host dashboard |

## Layout

```
src/app/            screens (Expo Router; web first, Android/iOS from the same code)
src/components/     UI, charts, calendar, map (Leaflet on web)
src/lib/            API wrappers for the SQL functions, auth, formatting
supabase/migrations schema, policies, functions, jobs
supabase/tests      SQL tests on PGlite + PostGIS (no Docker)
supabase/seed.sql   demo hosts, stays, bookings, reviews (generated by scripts/build-seed.mjs)
scraper/            Dot Property parser, polite fetcher, robots.txt check, CLI
data/               hand-entered AirDNA and BSP figures
```

## Commands

```bash
npm install
npm run web                       # dev server
npm test                          # parser + SQL tests
npm run scrape -- --dry-run --city makati --pages 1
DATABASE_URL=… npm run scrape     # real run into the database
node scripts/build-seed.mjs       # regenerate supabase/seed.sql
./scripts/release.sh              # build and deploy to Cloudflare Pages
```

Set `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in `.env` (see `.env.example`).

## Data

Asking prices from [Dot Property](https://www.dotproperty.com.ph), read once a day (one request every
3 seconds, robots.txt respected, only aggregates shown). Short-stay figures from AirDNA's free market
pages; price index from the BSP. All stays, hosts and reviews are made-up demo data.
